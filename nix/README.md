# go-nvml — Nix Flake Development Environment

A modular Nix flake adapted from [nebula's nix/](https://github.com/randomizedcoder/nebula/tree/nix/nix)
flake. This flake adds a reproducible build and a pedantic Go static-analysis
pipeline for the go-nvml library.

go-nvml is a Go library (no `cmd/` binaries) that binds to NVIDIA's
libnvidia-ml.so. The library uses `dlopen` at runtime to find the .so, and
its cgo `LDFLAGS` use `-Wl,--unresolved-symbols=ignore-in-object-files`, so
the lint and build phases work in a clean nix sandbox without NVIDIA system
libraries present.

## Quick Start

```sh
nix develop                                 # enter dev shell
nix build .#go-nvml                         # build the library (pins vendorHash)
nix flake check -L                          # run every check
nix run .#govulncheck-go-nvml               # source-mode CVE scan (network)
```

## Static Analysis

Three tiers; the repo's existing `.golangci.yaml` is left alone — the nix
checks use their own configs under `nix/golangci/`.

| Tier | Attr | Runtime | Linters |
|---|---|---|---|
| 0 quick | `golangci-lint-quick` | ~30 s | gofmt, goimports, govet, errcheck, ineffassign, staticcheck, unused, copyloopvar, intrange |
| 1 standard | `golangci-lint` | ~2 min | tier 0 + gosec, gocritic, revive, contextcheck, sloglint, testifylint, unconvert, unparam, wastedassign, nilerr, perfsprint |
| 2 comprehensive | `golangci-lint-comprehensive` | ~10 min | tier 1 + exhaustive, prealloc, gocyclo, funlen, goconst, dupl, bodyclose, errorlint, misspell, nakedret, nestif, noctx, rowserrcheck, sqlclosecheck, whitespace |

Standalone checks:

- `go-vet` — `go vet -v ./...`
- `staticcheck` — Dominik Honnef's checker
- `gosec` — security scanner (`-exclude-generated`; same nebula G-code excludes)
- `nix-fmt` / `statix` / `deadnix` — Nix-side hygiene
- `govulncheck-go-nvml` (app, not check) — source-mode CVE scan against `./...`

## Generated code exclusions

`nix/golangci/*.yml` explicitly excludes c-for-go / moq / cgo-godefs output:

- `pkg/nvml/zz_generated.api.go`
- `pkg/nvml/types_gen.go`
- `pkg/nvml/dynamicLibrary_mock.go`
- `pkg/nvml/mock/*.go`

The other c-for-go files (`pkg/nvml/nvml.go`, `pkg/nvml/const.go`,
`pkg/nvml/doc.go`) carry standard `Code generated by ... DO NOT EDIT.`
headers and are auto-detected by golangci-lint's `generated: lax` setting.

## File map

```
flake.nix                       # inputs + eachSystem wiring
nix/
  README.md                     # this file
  constants.nix                 # version, ldflags, go toolchain pin
  shell.nix                     # dev shell
  checks.nix                    # tiered static analysis + standalone checks
  golangci/
    golangci-quick.yml          # tier 0
    golangci.yml                # tier 1
    golangci-comprehensive.yml  # tier 2
  packages/
    default.nix
    library.nix                 # buildGoModule (we only consume .goModules)
  apps/
    default.nix                 # govulncheck app
  static-analysis-report.md     # baseline run report
```
